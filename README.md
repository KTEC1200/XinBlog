## 🎯 功能特性

### 📝 内容创作

- **Markdown 文章系统**：代码高亮、LaTeX 数学公式、自动目录、阅读时长与浏览量统计，标签、封面、摘要一应俱全。
- **灵活的列表展示**：多种列表布局与文章卡片主题，后台实时预览；支持按标签浏览、站内搜索、分页与加载更多。
- **阅读与互动**：文章详情页可切换主题风格，点赞、分享，阅读体验完整。

### 💬 社区互动

- **评论系统**：支持回复、嵌套楼层，后台审核管理；新评论通过浏览器与邮件双重提醒。
- **留言墙**：弹幕、翻牌、时空隧道多种风格，支持匿名留言与审核流。
- **实时聊天室**：公共房、全体房、专属房任选，表情、图片、**语音 / 视频通话**应有尽有。
- **友链**：前台提交申请（可上传头像），后台审核、上线下线管理。

### 🤖 内置 AI

- **AI 写作助手**：文章生成、格式优化、智能摘要、对话润色，写作更省力。
- **AI 智能体**：深度思考 + 工具调用逐步推进，可联网搜索、读取站点数据，并直接执行文章、标签、评论、友链、用户等站点操作，全程可视化。
- **操作确认与回滚**：AI 执行写操作前在对话流内嵌确认卡片，经你点选确认后才真正执行；执行结果同样内嵌展示，支持 24 小时内一键回滚到操作前状态，回滚记录云端持久化、管理后台跨设备可查可管。
- **OpenAI 兼容接口**：可接入 Cursor、Obsidian、Continue 等常用工具。
- **自定义模型与密钥管理**：支持接入自己的模型服务，密钥独立可控、仅存后端。

### 🎨 主题与外观

- **多维度主题系统**：站点配色、文章卡片、详情页、聊天气泡、场景特效均可后台可视化调整，明暗模式一键切换。
- **个性化定制**：自定义字体、鼠标光标、背景、间距，导航栏自由配置。
- **首屏 Hero 布局**：拖拽式组合个人介绍、时钟、一言、音乐、文章、标签等组件，移动端自适应。

### 🔐 账号与安全

- **完整账号体系**：注册、登录、忘记 / 重置密码（邮箱验证）；个人中心可修改昵称、头像、简介与密码。
- **多场景人机验证**：算术、Turnstile、极验等多种方式，可分别应用到登录、注册、找回密码等场景。
- **三级权限**：用户 / 管理员 / 站主，注册、找回密码等能力均可由后台开关。

### 🎵 媒体与音乐

- **媒体库**：图片分片上传、用量统计、懒加载与图片代理，管理轻松。
- **音乐播放器**：支持网易云歌单与自定义歌曲，歌词显示、播放记忆、自动播放、后台继续播放，还可独立成页。

### 🧸 趣味功能

- **Live2D 看板娘**：内置多款模型，支持自定义模型来源，位置、大小、工具按钮均可调，可随时隐藏与唤起。
- **点击特效**：爱心、烟花、彩纸等多种粒子效果，随心切换。

### 🛠️ 后台与运维

- **可视化后台**：20+ 管理页面，文章、标签、媒体、评论、用户、友链、AI、聊天、留言墙、外观、看板娘、音乐、导航、协议等，站点的一切都能在后台配置。
- **数据概览**：文章、评论、点赞、注册、阅读量趋势一目了然，支持多时间段查看。
- **邮件系统**：支持多种发送方式，模板可在线编辑，验证码与各类通知自动发送。
- **协议与隐私政策**：Markdown 在线编辑，前台自动展示。
- **PWA 支持**：可安装到桌面，像原生应用一样使用。

## 🏗️ 技术架构

项目专为 Cloudflare 免费套餐设计，全栈零服务器成本：

- **前端**：React 19 + Vite 构建的单页应用，托管于 Cloudflare Pages 静态托管。
- **后端**：Cloudflare Pages Functions 提供全部 API 能力。
- **数据库**：Cloudflare D1（SQLite 边缘数据库），按用户、文章、配置、媒体分库存储。
- **AI 能力**：Cloudflare Workers AI 模型推理，同时支持自定义模型。
- **实时能力**：独立聊天服务（WebSocket），支撑聊天与通话信令。

## 📁 目录结构

```
src/
├── api/        统一 API 客户端与各业务接口封装
├── components/ 通用组件 / 前台框架 / 文章 / 评论 / 聊天 / 音乐 / 看板娘 / 后台
├── pages/      页面层（前台 + admin 后台）
├── router/     集中式路由（含权限守卫）
├── stores/     Zustand 状态层
├── theme/      运行时主题生成
├── themes/     内置主题包（站点 / 文章卡片 / 详情页 / 聊天气泡 / 场景特效）
├── types/      类型定义
├── utils/      工具函数
└── hooks/      自定义 Hook

db/       数据库初始化 SQL 与说明
public/   后端 Worker（_worker.js）与静态资源
```
